## How it works (max ~10 lines)
- UPLOAD RULES (S2): any new file field must use `mimes:` (content-sniffed) + `$file->store()` (extension from content), never getClientOriginalName as a path; chat uses SafeUpload (allow list jpg png gif webp pdf doc(x) xls(x) ppt(x) txt csv zip, 10 MB, uuid name, canonical type); html/svg/php/xml/js/exe rejected. Files are on the public disk (no login to fetch, random names) - known residual risk.
- Required documents come from the intern's course (see COURSE REQUIREMENTS above); the old fixed list is only the default. Documents: intern (needs current deployment, else 422) or coordinator uploads; jpg/jpeg/png/pdf/doc/docx, max 5 MB, public disk at documents/{schoolId}; status starts pending. Coordinator approves/rejects (+remarks); intern notified, ActivityLogService records.
- Coordinator document list scoped to the school's deployment ids; dashboard uses documents?status=pending.
- Portfolio: one row per intern, firstOrCreate on intern visit; items have optional image (jpg/png/webp/gif, max 3 MB, portfolio/{internId}) and URL. No approval flow. Coordinator/supervisor views are read-only; portfolio is null if never created.
- Coordinator intern report: hours/tasks/attendance counts/evaluations JSON; frontend uses window.print().
- Narrative AI: intern polishNarrative returns 503 if no Gemini key configured, error if generation returns null; generateFromTasking is used for activity narratives (see activities log).
- Downloads: file_url is the Storage public URL; UI routes through /api/download?path=storage/...&name=...

- Word export mirrors the screen (same payload): header repeats letterhead, each section pageBreakBefore, table header rows repeat, empty-source notes are screen-only so omitted. Needs ext-zip + gd (JPEG support makes images get downsized; without it originals are embedded). Print button still uses window.print.
- Narrative report: PDF/DOC documents cannot be embedded, so the page shows "Attached separately: file". Missing items show a grey screen-only note. No deployment office/department exists, so the title page uses the company name only. Logo comes from the coordinator upload (public disk narrative/{schoolId}); CHED seal is a static asset.
